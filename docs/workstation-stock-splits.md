# Split-adjusted charts and execution-label shortcut

Workstation charts request a split-adjusted view by default. CrowdStrike's four-for-one split became effective on July 2, 2026: pre-split OHLC prices divide by four and volumes multiply by four. This removes the artificial gap and lets price and volume moving averages use consistent units. The split comes from verified Alpaca corporate-action data, not a guessed price-gap threshold or a symbol-specific override.

Daily and intraday history reuse the existing raw candle cache. Adjustment happens when serving the chart response, so previously populated history is corrected without deleting or repopulating it. Hourly regular-session aggregation and session filtering retain their existing behavior. A weekly candle spanning a split cannot be corrected with one factor, so weekly views use Alpaca's native split-adjusted aggregate under a separate cache identity. Cash-dividend adjustments are not applied.

The metadata lookup is paginated, cancellable, shared across concurrent panels and cached in bounded process memory for five minutes. Only effective forward/reverse splits are included, using New York midnight on the ex-date. Split-history fingerprints separate chart series and adjusted weekly caches. A changed fingerprint requires a chart reload rather than mixing two price bases. On an initial metadata failure, the chart explicitly warns that split adjustment is unavailable and identifies the original provider basis. A failure cannot append raw bars to an already adjusted chart. Yahoo's unverified adjustment basis remains explicitly separate.

Execution markers use adjusted prices and equivalent share quantities; their details also show the original fill. Accounting, P&L, max notional, broker records and journal values remain unchanged. Existing drawing anchors are projected from their original price at each anchor date. New or edited anchors are converted back to that canonical basis for storage, including when dragged across a split. The coordinate editor displays the chart's adjusted prices. Replay and Before entry use the same adjusted data with their existing time filters. PNG, layout exports, clipboard images and attached screenshots use that same rendering path.

**Toggle execution labels** is available in Keyboard shortcuts, with **Shift+L** as its default. It affects only the focused chart, using the existing Labels button action; compact mode keeps execution markers visible. Remapping, clearing, conflicts, disabled shortcuts and typing exclusions retain their existing behavior. If Shift+L was already assigned on this device, the new command starts unassigned.

No database migration, cache purge, history-loading algorithm change or separate worker redeployment is required. Preparation continues storing raw data; charts apply the current split projection when reading it.

Validation covers 88 mocked provider/API/calculation cases, 44 workstation/history/shortcut regressions, 38 isolated PostgreSQL cache cases (including byte-for-byte preservation of existing raw candle payloads), and browser checks for focused shortcuts, 1–4 chart layouts, persisted drawing coordinates and adjusted PNG labels. Existing session, comparison, annotation and display regressions pass. Laptop/mobile views and an exported PNG were inspected; lint, application/validation type checks and the production build pass.

Sources: [CrowdStrike split dates](https://ir.crowdstrike.com/static-files/f774ef12-cf94-48bf-ace2-c7f3dcf8ec97), [Alpaca corporate actions](https://docs.alpaca.markets/us/reference/corporateactions-1), [Alpaca historical bar adjustments](https://docs.alpaca.markets/us/v1.4.2/reference/stockbars).
